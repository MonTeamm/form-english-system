# Input data

`soict_2026_survey_responses.csv` is the publicly shared, de-identified official 904-respondent dataset used for the reference analysis. It is a semicolon-delimited, UTF-8 CSV; do not change its contents if you intend to match the reference SHA-256.

`questionnaire.json` contains the complete 71-item question-text mapping used by phase 1. All other data files in this folder remain excluded by `.gitignore`.
